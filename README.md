# Student Performance Analysis Dashboard

## Project Overview
The Student Performance Analysis Dashboard is a beginner-friendly data analysis and web development project built to analyze students' academic performance and present the results through a dashboard.

## Technologies Used
- Python
- Pandas
- Flask
- HTML
- CSS
- Chart.js

## Features
- Calculate total and average marks.
- Identify the class topper.
- Calculate subject-wise average marks.
- Display pass and fail statistics.
- Visualize subject averages using a bar chart.
- Display student marks and attendance in a table.

## How to Run the Project

1. Clone this repository:
   `git clone https://github.com/NikhithaShaju/Student-Performance-Dashboard.git`

2. Install the required packages:
   `pip install -r requirements.txt`

3. Run the application:
   `python app.py`

4. Open your browser and visit:
   `http://127.0.0.1:5000`
